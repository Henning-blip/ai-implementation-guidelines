
# Standards für System-Prompts
Englische Übersicht über die Datei am Ende dieser Datei.

- Rolle definieren (define the role clearly): Die gewünschte Fachrolle des Systems muss eindeutig definiert sein, z.B. "Wissensverwalter" oder "Consultant".  
- Output-Format strikt vorgeben (specify strict output format in JSON/Pydantic): Der erwartete Ausgabefomat muss klar und streng geregelt sein, um Verwirrungen zu vermeiden.  
- Fallback-Szenarien bei Halluzinationen festlegen (set fallback scenarios for hallucinations): Wenn der System Irrtümer trifft, müssen替代 Szenarien definiert werden, um die Qualität der Ausgaben zu gewährleisten.

## English Overview at the End of This File.
- Define the role clearly: Specify the desired professional role of the system, e.g., "Knowledge Manager" or "Consultant."  
- Specify strict output format in JSON/Pydantic: Clearly define the expected output format to avoid confusion.  
- Set fallback scenarios for hallucinations: Define alternative scenarios when the system makes errors to ensure output quality.
